# quantumsure-utils

Shared quantum-resistant crypto utilities for QuantumSure.

- **ML-KEM-1024** (Kyber) key encapsulation
- **ChaCha20** symmetric encryption
- SHA-256 MAC integrity
- Private-key wrapping with a master password  
- encode and decode B64 with a single function call  

## Install

```bash
npm install quantumsure-utils
